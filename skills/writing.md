# Skill: letters, emails, documents, notes

## Rules
- Ready to send/use: clear opening, body with the actual details, clear closing or next step.
- Plain natural English (or the language asked for); short sentences; no filler ("I hope this finds you well" only if formal).
- Indian context: ₹ amounts, DD Month YYYY dates, Indian titles/addresses where relevant.
- Formal letters: sender, date, recipient, subject line, salutation, body, sign-off.
- Use [brackets] only for details that are truly unknown (e.g. [your roll number]), and keep them few.

## Checklist
- [ ] Every detail the user gave is included
- [ ] Right tone for the reader (teacher, client, friend)
- [ ] No placeholder text except truly unknown details
