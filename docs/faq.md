# FAQ

**Does Zoha work on macOS or Linux?** Not yet. She is Windows first. Ports are welcome; see CONTRIBUTING.

**Is my voice sent anywhere?** Speech recognition runs on your computer. Only the text of your request goes to the brain you chose.

**Can she shut down my PC by accident?** No. Shutdown, restart and sleep always ask first and only act after your next message is a clear yes.

**How do I add a feature?** Drop a Python file in `plugins/` or a Markdown file in `skills/`.

**Where are my settings?** In `.env`. Run `python setup_wizard.py` to change them.
